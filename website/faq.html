Getting Started
How do I install MAC Addy Spoofer?

Download MAC Addy Spoofer from the Mac App Store or the official site. Once downloaded:

  1. Open the .dmg file and drag MAC Addy Spoofer to your Applications folder.
  2. Launch the app — macOS may show a Gatekeeper security dialog on first launch.
  3. Right-click the app icon and choose Open to bypass the initial warning.
  4. On first use, the app will prompt for administrator credentials when applying MAC changes.
The app won't open on first launch — "unidentified developer" warning

macOS Gatekeeper may show a warning for newly downloaded apps. To open MAC Addy Spoofer:

  1. Right-click (or Control+click) the app in Finder.
  2. Select Open from the context menu.
  3. Click Open in the security dialog that appears.

Alternatively, go to System Settings → Privacy & Security and click Open Anyway. You'll only need to do this once.

How do I set up my network interfaces?

MAC Addy Spoofer uses macOS interface IDs (like en0, en1) to identify your network adapters. The defaults are:

  • Wi-Fi: en0 (most common on MacBook)
  • Ethernet: en1 or en2
  • Bluetooth: en2 or en3

To find your exact interface IDs, open Terminal and run:

ifconfig -l

Then update the values in Settings → Interface Mapping to match your Mac.

What macOS versions are supported?

MAC Addy Spoofer requires macOS 12 Monterey or later. It is optimized for macOS 13 Ventura, 14 Sonoma, and 15 Sequoia, and supports both Apple Silicon (M-series) and Intel Macs.

MAC Address Changes
Why does "Apply MAC" fail or show an error?

MAC address changes require root/administrator privileges. Common reasons for failure:

  • Incorrect interface name: Verify the interface ID in Settings → Interface Mapping matches your actual adapter (use ifconfig -l in Terminal).
  • Admin password rejected: Ensure you're entering the correct administrator password for your Mac account.
  • Interface is down: The selected interface must be active/up for the change to apply.
  • Script permission: The internal helper script may need execute permissions. Contact support if this persists.
Do MAC address changes persist after rebooting?

No. On macOS, MAC address changes made via ifconfig are temporary and revert to the hardware-burned-in address on reboot. This is a fundamental macOS behavior — the original MAC is stored in firmware and cannot be permanently changed via software.

This is actually a privacy feature: if you ever forget to restore your MAC, a reboot automatically returns you to your original address.

To re-apply after reboot, use the Automation tab to set a timer, or simply re-apply manually when you launch the app.

The app shows "Loading…" or doesn't detect my MAC address

This usually means the interface name configured in the app doesn't match your Mac's actual interface IDs. To fix:

  1. Open Terminal and run ifconfig -l to list all interfaces.
  2. Identify which interface corresponds to Wi-Fi (usually en0), Ethernet, or Bluetooth.
  3. Go to Settings in MAC Addy Spoofer and update the interface names accordingly.
How do I restore my original MAC address?

There are several ways to restore your original MAC address:

  • In-app: Click Restore on the Dashboard, or Restore Original in the MAC Configuration card.
  • Reboot: Simply restart your Mac — macOS automatically reverts to the hardware MAC address on boot.
  • Randomize All → Restore All: Use the Quick Actions panel to restore all interfaces at once.
Permissions & Security
How do I set up administrator/sudo access?

MAC Addy Spoofer requests your macOS administrator password each time it applies a MAC change. This is the same password you use to install software on your Mac.

For advanced users who want passwordless operation (not recommended for shared Macs), you can add a sudoers entry:

sudo visudo -f /etc/sudoers.d/macaddy

Add the following line (replace username with your account name):

username ALL=(root) NOPASSWD: /usr/sbin/ifconfig

Note: Only do this on a Mac you fully control, and understand the security implications of passwordless sudo.

macOS shows a Gatekeeper or security warning

This is normal for apps downloaded outside the Mac App Store. MAC Addy Spoofer is code-signed with a Developer ID and notarized by Apple, so it is safe to run.

To allow it: System Settings → Privacy & Security → Open Anyway. You only need to do this once.

Is MAC spoofing legal?

MAC address spoofing is legal in most jurisdictions when used on networks you own or are authorized to use. Common legitimate use cases include:

  • Enhancing privacy on public Wi-Fi networks
  • Network testing and development
  • Bypassing MAC-based access restrictions on your own network
  • Testing network security on authorized systems

Do not use MAC spoofing to impersonate other devices, bypass security controls you're not authorized to bypass, or for any fraudulent purpose. Always comply with your organization's policies and applicable laws.

Features
What are vendor presets and how do I use them?

Vendor presets generate MAC addresses that match the Organizationally Unique Identifier (OUI) of a specific manufacturer. This makes your device appear to be from that brand on the network.

Available presets: Apple, Intel, Cisco, Dell, HP, Samsung, VMware, and Random (fully random OUI).

Click a vendor chip in the MAC Configuration card, then click Generate to create a valid MAC address for that vendor, and Apply MAC to set it.

How do I clone a MAC address from another device?

Use the Clone MAC quick action on the Dashboard:

  1. Click Clone MAC in the Quick Actions panel.
  2. Enter the target MAC address in the format 00:1A:2B:3C:4D:5E.
  3. Click Clone to populate the MAC field.
  4. Click Apply MAC to apply it to the OS.
How do I randomize all interfaces at once?

Click Randomize All Interfaces in the Quick Actions panel (or use Cmd+Shift+G from the menu bar). This generates and applies a random MAC address to every configured interface simultaneously.

Each interface gets its own unique random MAC. You can also restore all interfaces at once with Restore All Original.

Can I save and load my MAC configuration?

Yes. Use File → Save Configuration (or Cmd+S) to export your current settings — including vendor preferences, interface mappings, and behavior settings — to a JSON file.

Use File → Load Configuration (or Cmd+O) to restore a saved configuration. This is useful for switching between different network profiles.

Automation
How does the auto-randomization timer work?

The Automation tab lets you schedule automatic MAC address randomization at a fixed interval. To set it up:

  1. Go to the Automation tab.
  2. Set the interval (e.g., 30 minutes, 1 hour) and select which interfaces to include.
  3. Click Start Timer. The countdown ring shows time until the next change.

The timer runs while the app is open. Each auto-change is logged to the History tab.

Will the timer keep running when I minimize the app?

Yes — the timer continues running as long as MAC Addy Spoofer is open, even if it's minimized or in the background. However, the timer pauses if you quit the application and does not persist across sessions.

Troubleshooting
My Wi-Fi disconnects when I apply a MAC change

This is expected behavior. Changing the MAC address requires the interface to briefly go down and come back up, which disconnects your Wi-Fi. The connection re-establishes automatically within a few seconds in most cases.

Your router will see the new MAC address and may assign a new DHCP lease (new IP address). Some networks with MAC filtering may require you to authorize the new address.

Bluetooth interface issues or unavailable

Bluetooth on macOS uses a different hardware stack than Wi-Fi and Ethernet. MAC address spoofing for Bluetooth via ifconfig may not work on all Macs or all macOS versions — Apple has progressively restricted Bluetooth interface access.

If the Bluetooth interface shows as unavailable, this is a macOS limitation. Wi-Fi and Ethernet interfaces are fully supported.

The change history isn't saving between sessions

MAC Addy Spoofer stores history in localStorage within the app's Electron context. If you're not seeing history persist, try:

  1. Go to File → Save Configuration to save your current state.
  2. Check that you haven't cleared app data or reset preferences.
  3. Use File → Export History as CSV to back up your history to a file.
The app crashes or becomes unresponsive

If MAC Addy Spoofer crashes or freezes:

  1. Force-quit the app (Cmd+Option+Esc) and relaunch it.
  2. Check Console.app for error logs related to MAC Addy Spoofer.
  3. Try resetting settings: go to Settings → Reset to Defaults.
  4. If the issue persists, email support@souriapps.net with a description of what you were doing and your macOS version.
