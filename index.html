How MAC Addy Spoofer works
This utility changes your network interface's MAC address — the hardware identifier your device shows to local networks — for privacy. Applying a change runs a privileged system command, so macOS asks for your administrator password each time (one prompt covers a whole batch). Changes are temporary and revert when you reboot. Everything runs on your device: no accounts, no network calls, no telemetry. Developed by SOURI APPS LLC.

Why does Apply MAC fail?

Applying a MAC runs a privileged system command through a macOS administrator prompt — no Terminal or sudo setup needed. If you cancel the password dialog, nothing changes. If a change is applied but the read-back doesn't match, check that the interface name in Settings matches your Mac (usually en0 for Wi-Fi) and that the interface is up.

Why doesn't the app detect my real MAC?

The app reads MACs via ifconfig through Electron IPC. Ensure interface names in Settings match your Mac's actual IDs (usually en0 for Wi-Fi).

Will MAC changes persist after reboot?

On macOS, changes made via ifconfig are temporary and revert on reboot. This is by design.

Why does the timer ask for my password?

Each timer rotation performs a real MAC change, so macOS shows the administrator prompt once per rotation. Dismissing the prompt skips that rotation; the schedule keeps running.

Can I change my Bluetooth MAC?

No — Bluetooth MAC changes are restricted on modern macOS. The Bluetooth tab is informational only.
